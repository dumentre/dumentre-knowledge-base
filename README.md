# Dumentre knowledge base

Shared reference for work across Dumentre projects. This repository stays next to the project repositories so common instructions and tools do not need to be copied into every codebase.

## Structure

| Folder | Contents |
|---|---|
| [`ai-instructions/`](ai-instructions/global-rules.md) | Common working rules and the source of truth for Dumentre-wide guidance. |
| [`skills/`](skills/README.md) | Catalog and recoverable copies of global agent skills used across projects. The active installation is in the local user skill store. |
| [`root-snapshots/`](root-snapshots/) | Snapshots of the AI instruction files kept at the Dumentre workspace root. |
| [`operations/`](operations/claude.md) | Operational records for Dumentre software subscriptions and renewal checks. |
| [`briefings/`](briefings/) | Work briefings for long autonomous sessions. |
| [`estrategia/`](estrategia/README.md) | Commercial strategy: diagnosis, offers, identity directions, site redesign, social, ads and prospecting (Oct/2026). |
| [`marca/`](marca/design.md) | Dumentre brand source of truth: `design.md`, `brand.md`, voice principles and SVG logo files. |
| [`backlog/`](backlog/README.md) | Decisions and approvals pending for Luan, prioritized. |

Client-specific strategy, brand approvals, content, assets and backlogs remain in their own project workspace. Do not put client photos or identifying information in the global skills library.
